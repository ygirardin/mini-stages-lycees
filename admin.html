Gérer les mini-stages
sans écrire de code.

Ajoutez et modifiez les fiches, puis exportez le fichier prêt à publier sur GitHub. Cet espace est un éditeur local : il n'envoie aucune donnée sur un serveur.

Ajouter un mini-stage

Une fiche correspond à une séance ou à une période d'immersion. Les champs marqués d'un * sont obligatoires. Renseignez séparément les dates de la séance et la période pendant laquelle les demandes peuvent être déposées. Laissez vide toute date inconnue.

Procédure : l'établissement scolaire de l'élève effectue la demande pendant la période indiquée. Le lycée d'accueil lui renvoie ensuite une convention.

Comment publier ?

  1. Renseignez les fiches à l'aide du formulaire.
  2. Téléchargez le fichier mini-stages.json.
  3. Sur GitHub, ouvrez data/mini-stages.json dans votre dépôt.
  4. Remplacez son contenu par le JSON exporté, puis validez la modification.
  5. Le catalogue sera actualisé après la publication GitHub Pages.

Enregistrer les données

L'export reprend toutes les fiches préparées dans cette page.

Reprendre des données

Les offres actuellement publiées sont chargées au démarrage. Vous pouvez aussi importer un fichier précédemment exporté.

À savoir : cette page n'est pas protégée par mot de passe, mais elle ne peut pas modifier le site en ligne. Seules les personnes autorisées à publier dans votre dépôt GitHub peuvent valider les changements.

Besoin d'aide ?

Le fichier README.md contient le guide d'installation sur GitHub Pages et les consignes de mise à jour.
